Thiết kế Cơ sở dữ liệu (Database Schema)

3NF Chuẩn hóa

Hệ thống lưu trữ dữ liệu trực tiếp vào file database/db.json thông qua Node.js File System, đồng thời cung cấp đầy đủ kịch bản SQL chuẩn hóa 3 bảng tại database/schema.sql:

1. Bảng Users (Người dùng)
  • PK UserID (INT, AUTO_INCREMENT)
  • FullName (NVARCHAR - Vương Thị Anh)
  • StudentCode (VARCHAR - 31241025843)
  • MonthlyBudgetLimit (DECIMAL)
2. Bảng Categories (Danh mục)
  • PK CategoryID (INT, AUTO_INCREMENT)
  • CategoryName (NVARCHAR)
  • FlowType (ENUM: INCOME / EXPENSE)
  • ColorHex (VARCHAR)
3. Bảng Transactions (Giao dịch)
  • PK TransactionID (VARCHAR)
  • FK UserID, CategoryID
  • Title, Amount, PaymentMethod
  • Status (COMPLETED / PENDING / CANCELLED)

Hệ thống Backend RESTful API

Node.js Port 3000
GET /api/transactions Lấy danh sách giao dịch & hạn mức
POST /api/transactions Thêm giao dịch Thu/Chi mới
PUT /api/transactions/:id Chỉnh sửa toàn bộ thông tin giao dịch
PATCH /api/transactions/:id/status Cập nhật nhanh trạng thái giao dịch
DELETE /api/transactions/:id Xóa vĩnh viễn giao dịch
PUT /api/budget Cập nhật hạn mức chi tiêu tháng
